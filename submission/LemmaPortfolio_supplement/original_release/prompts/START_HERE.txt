LEMMA PORTFOLIO V4 - OFFLINE CHAT TEST PACKET

The preserved released prompts are in DIRECT_PROMPTS/01.txt through 12.txt.
Use the same 12 files for every model. Each file must be pasted once into a
completely fresh chat. Do not combine files into one chat and do not ask a
follow-up question.

Together, the twelve files cover all 60 released test episodes and match the
blocks in the archived response PDFs under ../responses/. Those PDFs contain no provider logs, so
they cannot by themselves confirm the prompt bytes or chat settings used at the
time.

Before the first test, record every model you intend to test in one document:

Product | exact visible model label | exact visible mode | tier or unknown

If there is no mode selector, write NO SELECTOR. Keep web search, tools,
agents, connectors, memory, uploaded files, and prior-chat context off.

DIRECT-ONLY RUNS

For a direct-only run, use this order:

  DIRECT_PROMPTS/01.txt
  DIRECT_PROMPTS/02.txt
  ...
  DIRECT_PROMPTS/12.txt

Open a fresh chat for every file. Copy the full visible response into your
return document immediately, unchanged. Include refusals, errors, partial
responses, and formatting wrappers. Do not repair JSON yourself.

WHAT TO RETURN

Save each complete response unchanged as a separate .json or .txt file, using
the prompt number in the filename. A searchable PDF may be kept in addition,
but it does not replace the raw files needed by the scorer. RETURN_TEMPLATE.md
is an optional human-readable log. Screenshots are not required.

If a product visibly invokes a tool, search, another model, or a fallback,
preserve the response and note what appeared. If an explicit platform error
occurs before any mathematical output, preserve it. Do not silently retry.
